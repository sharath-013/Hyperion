# Hyperion

**5v5 Multiplayer Simulation Web Experience**

Live Website: [https://sharath-013.github.io/Hyperion/](https://sharath-013.github.io/Hyperion/)

## Overview
Hyperion is a futuristic, sci-fi themed multi-page website for a 5v5 battle arena simulation game.

### Pages & Navigation
- **Home (`index.html`)**: Hero banner, latest patch notes & news, gameplay trailer, shard roster previews, and platform downloads (Windows, macOS, Linux).
- **Esports (`Esports.html`)**: Global Finals announcements and live tournament league standings.
- **Community (`Community.html`)**: Official Discord CTA, upcoming developer events, and community contests.
- **Merchandise (`Merchandise.html`)**: Official apparel, collectibles, and accessory gear collections.
- **Sign In / Sign Up (`Signup.html`)**: Interactive authentication portal with responsive navigation back to the main simulation.

### Deployment
This site is configured for automatic deployment via **GitHub Pages** (supports both GitHub Actions and branch deployment from `main`).
